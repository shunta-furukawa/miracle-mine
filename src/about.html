ABOUT THE GAME

数字がつながる、せかいがひろがる。

Miracle Mine（ミラクルマイン）は、となりあう数字をなぞってお題の数をつくり、自分だけの蒸気飛行機を組み立てる無料の冒険パズルです。スマホ・タブレット・PCのブラウザでそのまま遊べます。

あそびかた

  1. 5×5 の盤面に、0〜9 の数字が刻まれた鉱石が並んでいます。
  2. となりあう鉱石（ななめも OK）を指でなぞってつなぎます。つないだ数の合計が、画面上のお題の数とぴったり合えば成功。
  3. お題より小さければ、鉱石はひとつに合体して残ります。次の一手の材料にしましょう。
  4. 時間とともにライフが減ります。成功するとライフが回復します。
  5. 火山の章から「×」が使えるようになり、掛け算のお題が登場します。

森・海・洞窟・火山・高原の 5 章、全 30 ステージ。章をクリアするたびに飛行機の部品が手に入り、5 つそろうと初飛行へ。完成した飛行機に名前をつけて、隠し第 6 章「トトじいと空の旅」で飛距離ランキングに挑戦できます。

対象と端末

足し算ができれば遊べます。目安は小学校 1〜4 年生くらいですが、大人が遊んでも歯ごたえがあります。数字の色だけに頼らず、数字と紋章でも見分けられるようにしています。

iPhone / iPadSafari で開いて、共有メニューから「ホーム画面に追加」。横向きで遊んでください。
AndroidChrome で開いて、メニューの「ホーム画面に追加」または「アプリをインストール」。
PC / Chromebookブラウザで開くだけ。マウスでもキーボードでも遊べます。学校の端末でもインストール不要です。

一度読み込めば、以後はオフラインでも遊べます。iPhone では Safari とホーム画面のアプリで記録が別に保存されることがあります。

安心して遊ぶために

  • 無料です。課金やアイテム販売はありません。
  • 広告はありません。外部サイトへ誘導する仕組みもありません。
  • 登録不要。アカウント作成やメールアドレスの入力はありません。
  • 冒険の記録は遊んでいる端末のブラウザの中だけに保存されます。
  • ランキングに参加するときの飛行機の名前は、みんなに見えます。本名や連絡先は入れないようにお願いしています。乱暴な言葉や連絡先を含む名前は登録できません。

プライバシーについて

端末の中に保存されるもの

クリアしたステージ、集めた部品、飛行機のデザインと名前、ハイスコア、音の設定。これらはブラウザの保存領域（localStorage）にあり、開発者には送られません。

サーバーに送られるもの

ランキング参加「ランキングに参加して飛ぶ」を選んだときだけ、飛行機の名前・デザイン・飛距離・お題の達成記録を送ります。参加者の識別には端末で作ったランダムな鍵を使い、サーバーには鍵のハッシュ値と発行した ID だけを保存します。名前・端末・個人を結びつける情報は持ちません。上位 100 機の名前とデザインと飛距離が公開されます。
共有カード共有ボタンでつくるリンクには、飛行機の名前・デザイン・記録など、カードに描かれる内容だけが含まれます。サーバーには保存されません。
利用状況の計測共有ボタンが押された回数などをサーバーのログに記録します。名前や ID は含みません。ページの閲覧数は Vercel Web Analytics で集計します。Cookie を使わず、個人を特定しません。

削除のお願い

ランキングの記録を消してほしいときは、お問い合わせから飛行機の名前と達成した飛距離をお知らせください。端末の中の記録は、ゲーム内の「データを消す」か、ブラウザのサイトデータ削除で消せます。

この内容を変えるときは、このページを更新してお知らせします。

開発者より

桁の多い計算も、分けていけば一桁どうしの計算です。10 という境目の感覚と、掛け算の手触り。数字に慣れた大人が忘れてしまった「数字と遊ぶ感覚」を、これから数字と出会う子どもに手渡したくて、お題の数を作るゲームにしました。何と何を組み合わせればこの数になるのか。物語に沿って、何度も遊んでもらえたら嬉しいです。

この思いの全文は X（@MiracleMine0123） でも綴っています。
