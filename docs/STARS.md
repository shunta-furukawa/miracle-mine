# 三つ星評価（第1〜5章のステージ）

やり込み要素として、30ステージそれぞれに3段階の星を付ける。星は工房（セーブスロット）ごとに保存され、地図・セーブ一覧・クリア画面・ステージ導入カードに表示される。全ステージ3つ星で 90 / 90。

## 指標

- **タイム**: 導入カードで「はじめる」を押してからクリアまでの実プレイ秒数。ポーズ、会話、章のカットイン中は止まる。0.1秒単位で記録。「ゆっくりライフ」設定は影響しない。
- **割った回数**: なぞった結果がお題にも合体にもならず、石が消えた回数（お題より大きい、または10以上でお題未満）。

## 評価

`src/stars.js` の定数で調整する。

| 章 | 1ゴールあたりの基準秒数（`STAR_PACE`） |
| --- | --- |
| 1 | 8 |
| 2 | 9 |
| 3 | 10 |
| 4 | 12 |
| 5 | 14 |

- 基準タイム = 基準秒数 × そのステージの必要ゴール数（`stages[].count`）。
- ★★★: 基準タイム以内、かつ割った回数 0。
- ★★: 基準タイム × 1.6（`TWO_STAR_FACTOR`）以内、かつ割った回数 2（`TWO_STAR_BREAKS`）以下。
- ★: クリア。

## 記録

- セーブの `slots[].stars[stageId] = {stars, time, breaks}`。既存セーブには空の `stars` が補われ、クリア済みで記録のないステージは地図に「✓」のまま表示される。
- 保存するのは最良の1回。星が多い方、同じなら割った回数が少ない方、同じなら速い方。クリア画面では更新時に「新記録！」を表示する。
- クリア画面と失敗画面の「もう一度」（ゆっくりで再挑戦も）は章の会話シーンとステージ前の会話を飛ばし、すぐ導入カードから始まる（`retry:` アクション、`start(...,quick=true)`）。章末ステージ（x-6）のクリア演出にも「もう一度」があり、同じく会話を飛ばして再挑戦できる（組み立ての振り返りには出ない）。地図から選び直したときは会話が流れる。
- 導入カードの星パネルは2段: 「きみの記録」（星・タイム・割った回数）と「3つ星の条件」（秒数・割らない）。暗い背景に明るい文字とチップで表示し、狭い画面ではチップが下段に折り返す。
- ステージクリアの共有カードには星とタイムが載る（共有時点のスナップショット）。
