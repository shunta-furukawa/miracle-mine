# Miracle Mine リリース広報戦略

対象バージョン: 0.19.x → 1.0 正式リリース。前提は「個人開発・予算ゼロ・無料・広告なし・登録不要」。
本ドキュメントは戦略の合意用で、実装や投稿を自動化するものではない。

## 1. 何を売るのか（ポジショニング）

一言: **「数字をなぞって、自分だけの蒸気飛行機を組み立てる。無料で安心して渡せる子ども向けパズル」**

タグライン（既存）: 数字がつながる、せかいがひろがる。

差別化ポイントは 3 つに絞る。

| 軸 | 事実 | 誰に刺さるか |
| --- | --- | --- |
| 安心して渡せる | 無料・広告なし・課金なし・登録不要・データは端末内のみ・オフライン可 | 保護者・先生 |
| 遊びの中で計算 | 足し算 6→8→10、火山で掛け算解放、高原で混合。教材ではなく冒険 | 保護者・子ども |
| 自分の飛行機 | 5 部品を集めて組み立て、翼・塗装・プロペラ・エンブレムを選び、名前を付けて空の旅ランキングへ | 子ども・拡散 |

言わないこと: 「計算力が上がる」「学力向上」などの効果断定。「計算に親しむ」「足し算・掛け算で遊ぶ」までに留める（景表法・誇大表示の回避）。

## 2. 誰に届けるか

子どもは自分で探して来ない。**見つけるのは大人、続けるのは子ども**という前提で設計する。

1. **一次: 保護者**（小学 1〜4 年の子を持つ 30〜40 代）。X / Instagram / Threads で知育・家庭学習アカウントをフォローしている層。決め手は「安全・無料・すぐ遊べる」。
2. **二次: 教員・学童・塾**。GIGA スクール端末（Chromebook / iPad）でインストール不要のブラウザで動くことが最大の訴求。すきま時間・計算のウォームアップ用途。
3. **三次: 個人開発者・インディーゲーム界隈**。拡散力が高く、開発ストーリー（Vercel 無料枠・PWA・Neon・OGP 動的生成）に反応する。ゲーム本体ではなく「作り方」で届く層。
4. **プレイヤー本人（子ども）**: 共有カードと空の旅ランキングで、遊んだ子が家族・友だちに見せる導線を担う。

## 6. ゲーム内の広報仕掛け

既にあるものを活かし、追加は小さく保つ。

既にある:
- 全 11 画面の共有カード + X 投稿導線 + OS 共有。
- `?via=share&kind=…` による流入元記録と `start` イベント。
- シーズン制ランキングと名前付き機体。
- PWA インストール（`beforeinstallprompt` を捕捉済み）。

追加候補（優先順）:
1. 静的な紹介ページ（`/about` または `/press`）。検索エンジンと SNS プレビュー用に文章・スクショ・遊び方を HTML で置く。現状 SPA の `index.html` は本文がなく検索に弱い。
2. 共有カードの `visit` / `start` に加え、通常訪問と初回セーブ作成を同じ `share-event` ログに乗せる。DB 追加なしで「共有経由 vs 直接」の比率が分かる。
3. 機体名の公開前フィルタ（対応済み）。`src/name-filter.js` の NG 語・連絡先チェックを、名前の保存時・ランキング出発時・ランキング表示時・共有カード描画時の全てに通す。通報導線は未着手。

確認済みで追加不要のもの:
- `/api/share?…&image=1` は既に `Cache-Control: public, max-age=86400, s-maxage=31536000, immutable` を返し、Vercel の CDN が同じカードを再描画しない。

## 7. 計測と目標

永続的な分析 DB は持たない方針を維持し、Vercel Web Analytics（無料枠）と既存の runtime logs で足りる範囲に絞る。

見る指標:
- 訪問数と流入元（`via=share` 比率）。
- 新規セーブ作成数（`start`）。
- 共有ダイアログ `open` → `x` の転換率。
- ランキング登録機体数（Neon の `mm_pilots` 件数）。
- PWA インストール数（`appinstalled` を 1 イベント追加すれば取れる）。

初月の目標は控えめに置き、翌月に見直す。

| 指標 | 初月目標 |
| --- | --- |
| ユニーク訪問 | 1,000 |
| 新規セーブ | 300 |
| 共有カード投稿（X 上で確認できた数） | 50 |
| ランキング登録機体 | 30 |

## 8. リスクと対策

- **無料枠の上限**: Vercel Hobby は帯域 100 GB/月、Function 実行時間に上限があり、商用利用不可。無料・非営利のまま運用するなら規約上は可だが、OGP 画像は CDN キャッシュ済みなので、詰まるとすれば初回描画とランキング API。Neon Free はコンピュート時間の上限があり、超えるとランキングだけ 503 になる（ゲーム本体は動く）。
- **AI 生成アート**: ゲーム界隈では賛否が強い。隠さず、前面にも出さない。プレスキットと記事の制作クレジット欄に「キャラクター・背景は画像生成ツールで制作、音楽は PeriTune（CC BY 4.0）、効果音は Kenney（CC0）」と明記し、聞かれたら答える。批判に反論しない。
- **子どものプライバシー**: 「端末内保存・アカウントなし・個人情報を送らない」は最大の強みなので、記事と紹介ページに必ず書く。ランキングの機体名だけが公開情報になるので、名前入力欄の注意書きと NG 語・連絡先フィルタ（対応済み）で守る。
- **効果表現**: 学習効果の断定を避ける（第 1 節）。
- **商標**: 「Miracle Mine」「ミラクルマイン」で J-PlatPat を一度検索し、衝突があれば副題で回避する。
- **端末差**: iOS のホーム画面アプリは Safari とストレージが別。「Safari で遊んだ記録はホーム画面版に引き継がれない」を FAQ に書く。

### 名前の調査結果（2026-09-16）

- **商標**: 特許庁公報を収録する patent-i.com で「ミラクルマイン」「MIRACLE MINE」とも出願・登録 0 件（称呼検索でも 0 件）。J-PlatPat 本体はこの環境から到達できなかったので、最終確認は開発者が J-PlatPat の商標検索で同じ 2 語を引くこと（数分）。
- **既存の使用例**: コナミのアーケードメダルゲーム「アニマロッタ」シリーズ（8 作目「勇者アニマと竜の秘宝」以降）に、シークレットゲーム「ミラクルマイン」がある。コナミは「アニマロッタ」を第 9・28・41 類で登録済み（登録 6270887）だが、「ミラクルマイン」単体の登録は見当たらない。
- **判断**: 法的な衝突は確認できない。ただし「ミラクルマイン」で検索するとアニマロッタ関連が上位に出るため、検索と SNS での発見性で不利。対策は名前を変えることではなく、常に「Miracle Mine ｜ ミラクルマイン 数字パズル」のように副題を添え、ハッシュタグは `#ミラクルマイン` に加えて `#MiracleMine` を併用すること。メダルゲーム側の話題と混ざるリスクは小さい。
